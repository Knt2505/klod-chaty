# Клод і Чаті

Telegram-група з двома AI-друзями. Повна специфікація: [docs/spec.md](docs/spec.md).

**Етап 1 (скелет):** обидва боти живуть у групі, відповідають на твої повідомлення, бачать спільну історію.
- Відповідає той, до кого звернулись (на ім'я або reply). Якщо ні до кого, продовжує той, хто говорив останнім, іноді підхоплює інший.
- Якщо ти пишеш кілька повідомлень поспіль, вони чекають ~8 с тиші і відповідають на все разом.
- Клод працює на Claude Haiku 5.5, Чаті на GPT-5.4 mini.
- Пам'яті, ініціативи й розмов між собою ще нема, це наступні етапи.

## Запуск: покроково

### 1. Два боти в @BotFather
1. Відкрий [@BotFather](https://t.me/BotFather) → `/newbot` → ім'я `Клод` → username, наприклад `klod_xxx_bot`. Збережи токен.
2. Ще раз `/newbot` → `Чаті` → `chaty_xxx_bot`. Збережи токен.
3. **Тільки для Клода:** `/setprivacy` → обери бота Клода → `Disable`. Без цього він не бачитиме твоїх повідомлень у групі.
4. За бажанням: `/setuserpic` для аватарок.

### 2. Група
1. Створи групу в Telegram і додай обох ботів.
2. Якщо міняв privacy вже після додавання, видали Клода з групи і додай знову.

### 3. API-ключі
- **Anthropic:** [console.anthropic.com](https://console.anthropic.com) → API Keys → Create Key. У Billing поповни баланс (мінімум ~$5).
- **OpenAI:** [platform.openai.com](https://platform.openai.com) → API keys → Create. У Billing поповни баланс (мінімум ~$5).

### 4. VPS
1. Орендуй найменший сервер з Ubuntu 24.04 у США (Hetzner, DigitalOcean чи подібні, ~$4–6/міс).
2. Підключись: `ssh root@<IP-сервера>`
3. Встанови Docker:
   ```bash
   curl -fsSL https://get.docker.com | sh
   ```

### 5. Код і налаштування
```bash
git clone <адреса репозиторію> klod-chaty
cd klod-chaty
cp .env.example .env
nano .env        # встав 2 токени і 2 API-ключі; CHAT_ID і OWNER_ID поки порожні
docker compose up -d --build
```

### 6. Прив'язка до твоєї групи
1. Напиши в групі `/ids`. Клод відповість двома числами: `CHAT_ID` і `OWNER_ID`.
2. Встав їх у `.env` (`nano .env`) і перезапусти:
   ```bash
   docker compose up -d --force-recreate
   ```
3. Тепер боти відповідають тільки тобі і тільки в цій групі.

Якщо колись перестануть відповідати після змін у налаштуваннях групи: Telegram міг змінити її ID. Знову `/ids` і онови `CHAT_ID`.

### Корисні команди на сервері
```bash
docker compose logs -f --tail 50          # дивитись логи
docker compose up -d --build              # оновити після змін у коді (після git pull)
docker compose down                       # зупинити
```
Історія переписки зберігається в `data/klod_chaty.db` і переживає перезапуски.

## Перевірка етапу 1
- [ ] «Клод, привіт» → відповідає Клод.
- [ ] «Чаті, як ти?» → відповідає Чаті.
- [ ] «Клод і Чаті, що думаєте?» → відповідають обидва, другий бачить відповідь першого.
- [ ] Reply на повідомлення Чаті → відповідає Чаті.
- [ ] Три повідомлення поспіль → одна відповідь на все разом.
- [ ] Ніхто не обіцяє «нагадаю» чи «піду з тобою».
- [ ] Повідомлення від когось іншого в групі ігноруються.
